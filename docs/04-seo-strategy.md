# SEO Strategy & Topical Authority

This document covers high-level strategic SEO audits that go beyond single-page optimization.

## 1. TASM (Total Addressable Search Market)
- Map the site's content against the buyer's journey:
  - **TOFU (Top of Funnel)**: Awareness-driven, broad informational queries.
  - **MOFU (Middle of Funnel)**: Consideration-driven, comparisons, "how-to" specific.
  - **BOFU (Bottom of Funnel)**: Conversion-driven, "best", "review", "pricing", "vs".
- The audit should identify if the site is missing content in any of these critical funnel stages.

## 2. Topical Authority Builder
- Ensure the site has a clear Pillar & Cluster model.
- **Pillar Pages**: Broad overview of a core topic.
- **Cluster Content**: Deep dives into specific subtopics, all linking back to the pillar page.
- Audit for "Orphaned Content" (cluster pages with no internal links) or missing pillar pages.

## 3. Search Intent Reverse Engineering
- For the targeted keywords, verify the content matches the intent:
  - **Informational**: User wants to learn (needs guides, lists, FAQs).
  - **Commercial**: User is researching before buying (needs reviews, comparisons).
  - **Transactional**: User wants to buy (needs product pages, clear pricing).
  - **Navigational**: User is looking for a specific page.
- If a page targets a commercial intent query but is formatted as a pure informational blog post without CTAs, it fails the intent match.

## 4. EEAT (Experience, Expertise, Authoritativeness, Trustworthiness)
- **Author Bios**: Are authors clearly listed with credentials?
- **Sourcing**: Are claims backed by external authoritative links?
- **Transparency**: Clear privacy policies, terms of service, and physical addresses (for local businesses).
